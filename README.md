
# Visonic GUI

This is the Home Assistant integration for controlling and monitoring your Visonic alarm system.

## Installation

1. Clone this repository to the `custom_components/visonicgui` directory in your Home Assistant configuration.
2. Restart Home Assistant.
3. Go to the **Configuration** > **Integrations** and search for **Visonic GUI** to set it up.

## Configuration

Configure the Visonic Alarm system with the following parameters:

- **Host**: IP address or hostname of your Visonic alarm system.
- **App ID**: Your application ID.
- **User Code**: Your user code for the Visonic system.
- **User Email**: Your user email.
- **User Password**: Your user password.
- **Panel ID**: The ID of your alarm panel.
- **Partition**: The partition to control (default is `ALL`).
